# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: open the
[Security tab of qucelerate/ai-gateway](https://github.com/qucelerate/ai-gateway/security)
and choose **Report a vulnerability**. Please do not open a public issue,
pull request or discussion for a suspected vulnerability.

Include what you can of: the affected component (inference API, admin API or
UI, a provider adapter, a client library, the container images or chart), the
version, steps to reproduce, and the impact you expect. Do not include real
credentials, tenant data or prompts; redact them.

## Scope and expectations

QuCelerate AI Gateway is open-source software provided under the MIT
license, without warranty and without a commercial support offering. Reports
are reviewed by the maintainers on a best-effort basis; there is no
guaranteed response time and no bug bounty.

Fixes ship in the next release (a `Release vX.Y.Z` commit on `main`, with a
CHANGELOG entry); there are no maintained release branches yet, so upgrade
to the latest release to get them.
