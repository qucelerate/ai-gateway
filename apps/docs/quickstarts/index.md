# Quickstarts

Short examples use curl and safe, bounded payloads. Set `GATEWAY_BASE_URL` and `GATEWAY_API_KEY` in the [installation quickstart](/quickstarts/installation.md); examples read both values from your shell.

If you can sign in to your organization's admin console, its **Playground** page sends a chat request to your models, with tools if you define them, and shows the same request as code in curl, Python, JavaScript, Rust, Go, Java and C/C++, with the gateway clients or as raw HTTP.
